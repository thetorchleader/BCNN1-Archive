Google Code Project Shutting Down in January 2016

March 15, 2015 Technology

The Google Code project hosting service will shut down in January 2016.

Nine years after the system’s launch, program managers spend more time managing spam and abuse on the site than hosting development projects.

“After profiling non-abusive activity on Google Code, it has become clear to us that the service simply isn’t needed anymore,” Open Source Director Chris DiBona wrote in a blog post.

Google has already disabled new project creation, with plans to shutter the service in about 10 months, on Jan. 25. Users can migrate their work from Google Code to GitHub using the exporter tool, or standalone services that move content to Bitbucket and SourceForge.

“When we started the Google Code project hosting service in 2006, the world of project hosting was limited,” DiBona said. “We were worried about reliability and stagnation, so we took action by giving the open source community another option to choose from.”

In the almost-decade since, a variety of what DiBona called “better” project hosting services—GitHub, Bitbucket—began to bloom, diverting attention away from Google Code. The Web giant itself even migrated nearly 1,000 of its own open-source projects to GitHub, in an effort to cozy up to developers.
